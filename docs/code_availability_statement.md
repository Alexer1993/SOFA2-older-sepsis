# Code and data availability text for the manuscript

## Recommended statement

The cohort-extraction, data-processing, statistical-analysis, external-validation, and figure-generation code supporting this study is publicly available at GitHub: https://github.com/Alexer1993/SOFA2-older-sepsis. The repository includes database-specific cohort logic, analysis specifications, the patient-level bootstrap implementation, and scripts used to generate the reported analyses and figures. Individual-level MIMIC-IV and eICU-CRD data are not redistributed because access is governed by PhysioNet credentialing and data-use requirements. Qualified researchers may obtain the source databases directly from PhysioNet and run the code in their own authorized environment. A third-party MIMIC-IV SOFA-2 scoring implementation used locally could not be redistributed under its accompanying terms; the repository documents its required input-output interface and the remainder of the reproducible workflow.

## Repository citation format

Tan Y, Dai M. *Code for Baseline and Dynamic SOFA-2 Profiles in Older Patients With Sepsis*. Version 1.0.0. GitHub. 2026. https://github.com/Alexer1993/SOFA2-older-sepsis.

## Suggested response to the editor
