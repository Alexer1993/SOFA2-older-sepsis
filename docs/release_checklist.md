# Public release checklist

- [x] Create the GitHub repository.
- [x] Confirm that no third-party restricted SOFA-2 SQL files are present.
- [x] Confirm that no patient-level CSV, RDS, XLSX, database dump, or identifier-bearing file is included in the public archive.
- [x] Confirm that no passwords, tokens, local usernames, drive letters, or absolute personal paths are present.
- [ ] Run the R syntax check locally or through GitHub Actions.
- [ ] Create a GitHub release tagged `v1.0.0` if a fixed release snapshot is desired.
- [x] Add the final GitHub URL to the manuscript Data/Code availability declaration.
- [x] Cite the public repository in the response to the editor.

No Zenodo DOI is required by the reviewer comment; an archival DOI can be added later if desired.
