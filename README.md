# Baseline SOFA 2 and Early SOFA 2 Trajectories Stratify Mortality Risk in Older Patients With Sepsis

Final public reproducibility repository. No final-cohort exclusion criterion was based on SOFA-2 availability, a SOFA-2 total of 0, or SOFA-2 score range.

Final cohort anchors: MIMIC-IV 23,174 -> exclude 10,531 not meeting Sepsis-3 within 0-48 h -> 12,643. eICU-CRD 34,481 -> exclude 21,844 not entering the final adult sepsis-source cohort -> 12,637 -> exclude 1,200 missing/out-of-window sepsis timing -> 11,437.
